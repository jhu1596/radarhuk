📖 초음파 레이더 웹사이트 사용법

            
    
                
  1. 핀 번호 설정: 초음파 센서의 TRIG(기본 7번), ECHO(기본 8번) 핀과 서보 모터 핀(기본 4번)을 입력합니다.
    2. 
                
  2. 모터 각도 조절: [2️⃣ 모터 작동 각도 조절 탭]에서 모터의 최소/최대 회전 각도(예: 10° ~ 170°)와 왕복 주기 시간(기본 4000ms)을 조절합니다.
    3. 
                
  3. 로컬 서버 연결 & 업로드: 로컬 백엔드 서버를 실행한 뒤 [서버 상태 확인] → 포트 선택 → [⚡ 아두이노 레이더 코드 업로드] 버튼을 누릅니다.
    4. 
                
  4. 실시간 레이더 작동: [3️⃣ 실시간 초음파 레이더] 탭에서 [🔌 아두이노 시리얼 연결 (Web Serial)]을 누르고 아두이노 포트를 선택하면 angle,distance 데이터를 받아 레이더를 실시간으로 그립니다.
