🔌 초음파 레이더 핀 번호 설정

            

                아두이노에 연결된 초음파 센서(TRIG, ECHO) 핀과 서보 모터(SERVO) 핀 번호를 입력해 주세요.
            


            

                

                    
                    
                

                

                    
                    
                

                

                    
                    
                

            


            

                
            

        

    


    
    

        

            
📖 초음파 레이더 시스템 사용법

            
    
                
  1. 핀 번호 설정: 상단의 [핀 번호 설정]에서 초음파 센서의 TRIG(기본 7번), ECHO(기본 8번) 핀과 서보 모터 핀(기본 4번)을 입력합니다.
    2. 
                
  2. 모터 각도 및 주기 조절: 슬라이더로 모터의 최소/최대 회전 각도와 왕복 주기(초)를 조절합니다.
    3. 
                
  3. 로컬 서버 연결 & 업로드: 로컬 서버를 실행한 뒤 [서버 상태 확인] → 포트 선택 → [⚡ 아두이노 레이더 코드 업로드] 버튼을 누릅니다.
    4. 
                
  4. 실시간 레이더 작동: [🔌 아두이노 시리얼 연결 (Web Serial)] 버튼을 누르고 아두이노 포트를 선택하면 실시간으로 레이더를 그립니다.
    5.
